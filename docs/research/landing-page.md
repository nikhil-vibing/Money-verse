# Dhaniverse 2.0 — Landing Page Research Brief

> Research target: a landing page that converts cozy-RPG players, F&O-burned devs, and 16-year-old phone-natives into Day-1 players of a free, open-source Indian financial-literacy RPG. Steal shamelessly. Attribute always.

The goal is not "SaaS hero with a gradient and 3 feature cards." The first 4 seconds should feel like *a place you want to live in*.

---

## Section 1 — The Masters

### A — Sea of Stars · https://seaofstarsgame.com
- **Hero (4s):** Full-bleed animated sky over a painted horizon; *Solstice Warriors* logo rises like a JRPG title card. No CTA above fold; a soft "Wishlist / Buy" fades in ~2s later.
- **IA:** Hero cinematic → world synopsis (mythic register) → press quotes → screenshot gallery → character cards → soundtrack module (Mitsuda credit) → platform grid → footer.
- **Arc:** Sells *returning to a feeling* (90s JRPG nostalgia), earns it with screenshots, proves it with press. Features come last.
- **Motion:** Parallax sky, gentle ken-burns on shots; everything else still. Reduced-motion respected.
- **Trust:** Mitsuda composer credit, "from the makers of The Messenger," IGN/Eurogamer pulls.
- **Goal:** Wishlist / Buy — one CTA, repeated.
- **Copy that lifts:** *"A story-driven turn-based RPG inspired by the classics."* Twelve words; everyone knows what it is.
- **Steal:** The *delay* of the CTA. Let the world speak first.

### B — Stardew Valley · https://www.stardewvalley.net
- **Hero (4s):** One hand-painted illustration of the farm. Pixel logo. Two buttons: "Buy" and "About". No video, no parallax.
- **IA:** Hero → 4 season screenshots → "About" prose (3 paragraphs, like a letter) → press quotes → platform buy links → wiki/forum/Discord.
- **Arc:** Refuses to perform. Laid out like a 2003 indie homepage on purpose — that *is* the brand.
- **Motion:** None.
- **Trust:** PC Gamer/Eurogamer/Edge quotes; community links *are* the trust signal.
- **Goal:** Buy on $platform.
- **Copy that lifts:** *"You've inherited your grandfather's old farm plot in Stardew Valley."* A sentence from a fairy tale.
- **Steal:** Calm as differentiation. Most pages shout; Stardew whispers and wins.

### C — Sabotage Studio · https://www.sabotagestudio.com
- **Hero (4s):** WebGL diorama — pixel world tilts on cursor, layered parallax (sky/mid/ground), particle fireflies. No copy except the studio mark. Pixels look *expensive* — bloom, lights, depth fog. HD-2D-lite *as a website*.
- **IA:** Diorama hero → one-paragraph manifesto → game cards → press → contact.
- **Arc:** *We are craftspeople.* The site is the portfolio.
- **Motion:** Heavy but slow. Cursor parallax with rubber-band easing, no scroll-jacking.
- **Trust:** The diorama itself.
- **Goal:** Click into game pages.
- **Copy that lifts:** Studio name + diorama. Words barely needed.
- **Steal:** **A hero diorama that proves the game's visual promise on the web itself.** Single biggest steal for us.

### D — Balatro · https://www.playbalatro.com
- **Hero (4s):** Looping ~6s gameplay clip of cards exploding into score numbers. Logo + "Buy Now" + platform icons. The clip IS the pitch.
- **IA:** Clip → 3 punchy feature cards → press wall → trailer → buy.
- **Arc:** Shows the verb in motion. Loop understood in <10s.
- **Motion:** One looping clip; rest still.
- **Trust:** Game Awards GOTY nominee badge, Steam "Overwhelmingly Positive."
- **Goal:** Buy.
- **Copy that lifts:** *"A roguelike deckbuilder where common poker hands explode into outrageous combos."* Genre, verb, feeling in one sentence.
- **Steal:** **A looping hero clip that shows ONE verb at peak satisfaction.** For us: NPC hands over chai while a passbook diegetic-UI updates.

### E — Brilliant.org · https://brilliant.org
- **Hero (4s):** Centred interactive demo running in the hero. Headline *"Learn by doing."* One CTA.
- **IA:** Live interactive → category cards → 3-step how-it-works → testimonial wall → app CTAs.
- **Arc:** Edu site that refuses to look like school. Lets you *do* a tiny lesson before signing up.
- **Motion:** A real interactive, not a video. Needs reduced-motion fallback to static.
- **Trust:** Princeton/MIT-instructor credits, App Store rating, photographed testimonials.
- **Goal:** Signup → trial.
- **Copy that lifts:** *"Learn by doing."* Three words; the entire pedagogy.
- **Steal:** **Playable demo IN the hero.** For us: a "split your first ₹15k salary" interaction — no install, no signup.

### F — Zerodha Varsity · https://zerodha.com/varsity
- **Hero (4s):** Hand-drawn illustration (kid reading a book, pastel) over white. Module grid (1-17), each an illustrated card.
- **IA:** Illustrated hero → module grid → "Why Varsity" prose → app + YouTube + Hindi-library cards → footer.
- **Arc:** *Free forever, hand-made, Indian.* No urgency, no signup wall, no "limited offer." The opposite of broker aesthetic.
- **Motion:** None.
- **Trust:** Karthik Rangappa byline; 400K+ YouTube subs surfaced; Hindi library; on Govt Karmayogi platform.
- **Goal:** *Start Module 1* — no signup to read.
- **Copy that lifts:** *"Free forever."* In Indian fintech, a thesis statement.
- **Steal:** **Tonal calm + illustrated module grid + "Free forever" badge.** For us: 7-district map of hand-painted cards.

## Section 2 — Anti-patterns we reject

- **Robinhood-era brokers** (Groww, Upstox marketing): green/red tickers, "₹0 brokerage" urgency, fake P&L screenshots. We are the opposite.
- **Generic SaaS hero:** Gradient + "Get Started Free" + 3 feature cards + logo wall. Every B2B startup. Loses to anything authored.
- **Confetti gamification:** Mascot pestering, leaderboard bait, "streak!" stickers above fold. Trains dopamine bursts — Pillar 8 rejects.
- **Steam-page-on-the-web:** Bullet wall, FAQ accordion, system requirements. That's a store page, not a landing page.
- **Autoplay video with sound + cookie banner over the hero.** Instant bounce.

---

## Section 3 — Consensus patterns (3+ masters)

1. **One dominant visual carries the hero.** Stardew (illo), Sea of Stars (sky), Sabotage (diorama), Balatro (clip), Brilliant (demo). Words shrink, world expands.
2. **One CTA, repeated.** No triple-tap "Buy / Learn / Watch."
3. **Craft credits substitute for "social proof" logos.** Composer credits, GDC awards, Steam-rating pulls.
4. **Tone is the differentiator.** Stardew = letter; Varsity = teacher; Sea of Stars = mythic; Balatro = confident. None sound like a startup.
5. **Motion is restrained and reduced-motion-honouring.** One moving element at a time.
6. **The "what it is" sentence sits within 200 words of the top.** Genre + verb + feeling.

---

## Section 4 — Divergences / choices we make

| Choice | Why |
|---|---|
| **Diorama hero (Sabotage path) over single illustration (Stardew path)** | We must prove HD-2D-lite *on the web*. Diorama is our visual thesis. |
| **Playable micro-demo below the fold (Brilliant path)** | Edu product. The verb *is* the pitch — let users feel it before signup. |
| **"Free forever" badge above the fold (Varsity path)** | Pillar 8. In Indian context the most persuasive line we can write. |
| **No wishlist / no signup wall** | Web game. Conversion = *Play in Browser*. One click. |
| **Bilingual EN/HI toggle top-right** | Pillar 9. Saanvi prefers HI, Rohit EN, Ananya code-switches. |
| **No dev face / "indie hacker" story above fold** | Stardew earned that after shipping. We haven't. |

## Section 5 — Blueprint for Dhaniverse 2.0

### 5.1 Section list (top → bottom)

1. **Sticky utility bar** (12px): EN/HI toggle · GitHub stars · "Free forever, open-source" pill. Hides on scroll-down, returns on scroll-up.
2. **Hero diorama** — full-viewport parallax of a Chawl-Mohalla evening. Logo, one-sentence pitch, one CTA *"Step into Dhaniverse →"*. Secondary text-link: *"Watch the 60s trailer."*
3. **Playable beat.** 480×270 interactive: *"It's your first payday. Split ₹15,000."* Three drag-targets (Rent · Save · Spend). A tiny NPC reacts. No signup.
4. **Seven districts** — illustrated map; each district is a card with an NPC portrait + one-line domain ("Bank Bazaar — where you meet CA Lakshmi aunty").
5. **Pillars as promises** — 4 cards: *Hide the lesson in the verb · Mastery, not grind · Forgiveness, not punishment · Free forever, no dark patterns.* Each card: one illo, one sentence, one citation (Khan / Celeste / Duolingo / Varsity).
6. **For whom** — Ananya / Rohit / Saanvi as named portraits with one-line need + one-line outcome.
7. **Inspired by** — honest attribution rail: Stardew · Celeste · Duolingo · Khan · Varsity. No fake "as seen in."
8. **Anti-promise band** — black, white serif: *"No confetti. No leaderboards by P&L. No notifications hyping volatility. No paywalled lessons. Ever."* The moat.
9. **Open source / contribute** — GitHub card, license, good-first-issues, Discord.
10. **Final CTA** — repeat *"Step into Dhaniverse"* over a night-palette parallax. Footer: credits, a11y statement, contact.

### 5.2 Hero — 4-second narrative

**Visual:** Diorama of Chawl Mohalla at golden hour — terracotta rooftops, saffron sky, an indigo-shadowed alley with one lamp flickering on. Pixel art at internal 480×270, `image-rendering: pixelated`, 4 parallax planes (sky / silhouette / mid / foreground) tilting ±6° on cursor with rubber-band easing.

**Headline (serif display, two lines):**
> *Money, as an adventure. Set in an India you'll recognise.*

**Subline:** A free, hand-painted 2D RPG that teaches Indian financial literacy — without ever pretending speculation is a game.

**Primary CTA:** `Step into Dhaniverse →` · **Secondary:** `Watch the 60s trailer`
**Trust pill:** `Free forever · Open source · No accounts to start`

### 5.3 Tone of voice (one paragraph showing how a section reads)

> **The seven districts.** You start in Chawl Mohalla, where rent is ₹4,800 and the chai is ₹10. Cross the bridge to Bank Bazaar when you're ready and CA Lakshmi aunty will explain why an FD ladder is not, in fact, a real ladder. Each district teaches one domain. You unlock the next by *showing* you can live in this one — not by waiting, not by paying.

Calm, specific, Indian, second-person, no buzzwords. The voice of Varsity crossed with the warmth of Stardew's About page.

### 5.4 Motion strategy

| Element | Motion | Reduce-motion fallback |
|---|---|---|
| Hero diorama | 4-plane cursor parallax, lamp flicker (3-frame CSS keyframe @ 1.2s), particle dust @ 30% opacity | Static composite PNG @ 2× |
| Playable demo | Drag-and-drop, NPC sprite 4-frame idle | Static, click-to-place |
| District cards | Idle: still. Hover: 2px lift + portrait blink | No hover effect |
| Anti-promise band | None ever | n/a |
| Final CTA | Night-palette crossfade of hero | Static night version |
| Scroll | No scroll-jacking. Native scroll only. | n/a |

Rule: **never more than one moving element in the user's central vision at once.** Honour `prefers-reduced-motion: reduce` site-wide via a single `--motion-scale` CSS var flipped to 0.

### 5.5 Trust strategy (zero users yet)

In priority order:
1. **The diorama.** If the page looks like the game, the game looks credible.
2. **Open-source repo + license badge.** Show GitHub stars honestly, even at 12.
3. **Attribution rail** — *Inspired by Stardew, Celeste, Duolingo, Khan, Varsity.* Naming teachers is itself credibility (the Varsity move).
4. **Anti-Promise band.** Listing refusals is, in Indian fintech, more trustworthy than any testimonial.
5. **Named designer/dev under the fold.** One paragraph, one face, one email. Stardew-style.
6. **Curriculum line:** *"Mapped to NCFE & SEBI + Zerodha Varsity."* Citable, falsifiable.
7. **No fake metrics.** Zero "10,000 happy players" until true.

### 5.6 Mobile-first (target: Saanvi, 16, mid-range Android)

- Single column, 16px gutters. Hero scales to 100vw × 56vw, capped at 540px tall.
- CTA pinned to viewport bottom after hero — translucent terracotta bar with `Step in →`.
- Playable demo: tap-to-cycle targets instead of drag, 64px hit areas.
- Lang toggle becomes a Sheet, not a tab bar.
- District cards: horizontal snap-scroll carousel with dotted indicators.
- Anti-Promise band: vertical stack; each refusal is its own scroll-beat.
- Weight budget: **< 600 KB JS, < 800 KB images at 1×.** Pixel art compresses gloriously.

### 5.7 HD-2D-lite *on the web* — without shipping Phaser

We need bloom + parallax + soft lights + tilt-shift without a 1MB+ Phaser bundle on a marketing page.

- **Pixel art as PNG/WebP at internal 480×270**, scaled with `image-rendering: pixelated` (integer multiples) into 4 parallax `<div>` planes.
- **CSS parallax** via `transform: translate3d()` driven by one `mousemove` listener, `requestAnimationFrame`-throttled.
- **Bloom** = `radial-gradient` overlay with `mix-blend-mode: screen` over light sources.
- **Depth fog** = final plane `backdrop-filter: blur(2px)` + `opacity: 0.15`.
- **Lamp flicker** = 3-frame `@keyframes` @ 1.2s.
- **Tilt-shift** = two `backdrop-filter: blur(1px)` strips top + bottom.
- **Optional WebGL treat** (capability-gated): tiny Pixi.js displacement-map on the alley puddle. <40KB. Falls back to static.
- **Total cost:** ~120 KB images + ~3 KB JS + zero game-engine bundle.

A Phaser scene can hot-swap into the hero later. Not on day one.

### 5.8 Component list (Next.js 16 / App Router)

In `app/(landing)/` as Server Components except where marked `'use client'`:

- `<UtilityBar />` — sticky 12px; EN/HI toggle, GitHub stars (server-fetched, ISR @ 1h), Free-Forever pill.
- `<HeroDiorama />` *(client)* — 4-plane parallax + lamp flicker. Honours `prefers-reduced-motion`.
- `<HeroCopy />` — headline, subline, CTAs.
- `<PaydayDemo />` *(client)* — drag-and-drop; `useReducer`; no persistence.
- `<DistrictMap />` + `<DistrictCard />` — illustrated map, 7 cards, hover lift.
- `<PillarsRail />` — 4 promise cards with citation pills.
- `<PersonaTriptych />` — Ananya / Rohit / Saanvi portraits with need + outcome.
- `<InspiredByRail />` — honest attribution row.
- `<AntiPromiseBand />` — black band, 4 refusals, serif white.
- `<OpenSourceCard />` — repo, license, good-first-issues, Discord.
- `<FinalCTA />` — night-palette diorama + CTA repeat.
- `<SiteFooter />` — credits, a11y statement, contact, sitemap.
- `lib/motion.ts` — `useMotionPreference()` → `'full' | 'reduce'`.
- `lib/i18n.ts` — `useLocale()` + `en.json` / `hi.json`.
- **shadcn primitives:** `Button`, `Card`, `Badge`, `Toggle`, `Sheet`.
- **Animation:** Framer Motion only inside `<PaydayDemo />` and card hover. Hero parallax uses raw `requestAnimationFrame`.
- **Fonts:** *Fraunces* (display) + *Inter* (body) + *Atkinson Hyperlegible* (a11y option). Hindi via *Hind*.
- **Images:** `next/image`; pixel art uses `unoptimized` so `image-rendering: pixelated` survives.

## Section 6 — The single biggest steal

If we steal only *one* thing: **Sabotage's diorama-as-hero.** Combined with Varsity's tonal calm and Brilliant's playable-in-hero demo, that triad differentiates Dhaniverse 2.0 from every Indian fintech page and every generic indie-game site in the first four seconds. The rest is execution.
