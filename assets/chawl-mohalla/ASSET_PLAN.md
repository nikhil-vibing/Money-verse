## 2. Gap analysis — what we could NOT find under acceptable licences

These are honest gaps. Where the chawl needs Indian-specific imagery, the open-source pixel-art world has very little. We will either commission, hand-pixel in-house, or improvise via heavy recolour of CC0 generics.

| Gap | Severity | Plan |
|---|---|---|
| **Indian chai stall (32x16) with kettle, glasses, vendor behind counter** | HIGH | No free Indian-style chai-stall sprite found. The only good market-stall pack (TheStarvingArtificer) forbids redistribution. → **Commission** a 32x16 chai-stall + chai-glass + brass-kettle set OR hand-pixel in-house. Estimated effort: 1 artist-day. |
| **Dabbawala bicycle + tiffin tower** | HIGH | No CC0 bicycle pixel asset found in our search. → **Hand-pixel in-house** at 32x32. Estimated effort: 4-6 hours. |
| **AC compressors mounted on walls** | MED | No direct CC0 asset. → Will hand-pixel a 16x16 AC compressor sprite. ~2h. |
| **Iron-grille balcony railings with chawl-specific bends** | MED | Surt's CC0 Scraps has rough railings; Kenney Urban Kit has clean modern railings. → Composite + recolour. ~3h palette work. |
| **Hanging laundry on a string** | MED | No direct CC0 asset. → Hand-pixel 16x16 individual sari/kurta/lungi sprites animated to sway 2-frame. ~3h. |
| **Religious-icon corner (interfaith-respectful)** | MED | Cannot find a CC0 pixel asset for a Hindu/Muslim/Christian shelf — and we *don't* want to fake one. → Author in-house with a deliberately neutral "small framed picture + diya/candle" silhouette. ~2h. |
| **Indian-formal-wear character costumes (saree, kurta, lungi)** | HIGH | Our character base (anon 16x16) and Antifarea sprites are western-clothed. → Re-skin in-house. Estimated effort: 3-4 hours per named NPC × 8 NPCs = 24-32h, the bulk of district art work. |
| **Postman bag + letters** | LOW | Kenney UI / RPG icon packs include bag-shape generic icons → recolour to khaki postman bag. Letter envelope can be hand-pixelled at 16x16 in <1h. |
| **₹ rupee icon as pixel-glyph** | LOW | AntumDeluge currency pack has only generic coin/cash — no ₹. → Hand-pixel a 12x12 ₹ glyph in our font's style. <1h. |
| **Terracotta-roof tile pattern** | LOW | Kenney Urban Kit has flat roof tiles; we'll palette-swap to terracotta orange. <1h. |
| **Chai vendor (Ravi anna)** | MED | Antifarea merchant sprite reskinned — works as a base. Combine with hand-pixelled chai stall. |
| **Bhola seth (suspicious-friendly older man)** | MED | Sean Noonan "Top Down Smart Old Man" reskin → adds safari shirt, ledger in hand, slight slouch. |
| **Drumming Kid** | MED | Re-shrink anon-16x16-base male sprite to ~24px tall, add drum prop. ~2h. |

**Net commission/in-house work:** approximately **60-80 artist-hours** for the chawl-mohalla district to be fully populated. The OSS assets provide ~70% of the geometry; the *Indian-specificity* layer is almost entirely our work.

## 4. Deliverable manifest (this PR)

This curator pass produces *no binary art*. Outputs are:

1. `/assets/ATTRIBUTION.md` — 21 entries appended (15 PRIMARY, 5 ALTERNATIVE, 1 reference). 11 entries listed under REJECTED for licence-incompatibility transparency.

When the level-designer / game-dev engineer is ready to integrate, they should:
1. Read this plan + the corresponding ATTRIBUTION.md entries.
2. Run a fetch script that downloads only the PRIMARY packs to `assets/chawl-mohalla/_raw/<slug>/` with a `LICENCE` file dropped alongside each (CC0 deed text for CC0 packs; CC-BY 4.0 deed + attribution string for the George Bailey + Antifarea packs).

4. Hand-pixel the gap items in §2.

## 6. Confidence statement

**Geometry/structure of the chawl: ~70% covered by OSS.** Kenney RPG Urban Kit + Surt Town Tiles + George Bailey interiors + Kenney UI is enough to lay out an alley, a courtyard, a room, and the whole UI shell without writing a single new tile.

**Cultural specificity: ~25% covered by OSS.** The chai stall, dabbawala bicycle, AC compressor, hanging laundry, Indian-formal-wear NPC overlays, religious-icon corner, and the ₹ glyph all need in-house pixel work. This is unavoidable — the open-source pixel-art commons skews heavily Western-medieval / Japanese / generic-modern, with virtually nothing chawl-flavoured under acceptable licences. Plan accordingly: **the chawl will look like a chawl only after ~60-80 hours of in-house re-skin + hand-pixel work on top of the OSS substrate.**

**Cannot ship the district from OSS alone.** Can ship a *playable greybox* in 1-2 days. Can ship a *visually distinct chawl* in ~2 artist-weeks after this base is in place.
